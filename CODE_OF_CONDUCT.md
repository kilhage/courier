# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**. The full text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and is incorporated here by reference.

In short:

- Be kind and respectful. Welcome people of every background and level of experience.
- Give and accept constructive feedback gracefully. Focus on what is best for the project and the community.
- No harassment, discrimination, personal attacks, trolling, or publishing other people's private information.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when someone represents the project
in public.

## Enforcement

Instances of unacceptable behaviour can be reported to the maintainers through GitHub's private reporting
(repository *Security* tab → *Report a vulnerability* is for security issues; for conduct concerns, contact the
repository owner through their GitHub profile). Maintainers will review every report promptly and fairly, may
remove, edit or reject contributions that do not follow this code, and will respect the privacy of the reporter.

*Maintainers: add a dedicated conduct contact address here before publishing.*
